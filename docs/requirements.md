# HealthBridge 要件定義

## 1. 概要

HealthBridgeは、従業員が日々の体調を記録・振り返り、管理者が担当従業員の体調を把握するための体調管理・共有アプリです。

従業員は出勤時・退勤時に体調とコメントを記録し、自身の体調変化を履歴やグラフから振り返ります。管理者は担当従業員の記録を確認し、必要な声かけや配慮を検討するための情報として活用します。

本ドキュメントでは、スタッフレビューを通して整理したHealthBridgeのMVP要件を記載します。

## 2. 開発背景・解決したい課題

### 従業員側の課題

日々の体調は変化するため、その時点では気づきにくい変化でも、継続して記録することで傾向を把握しやすくなります。

HealthBridgeでは、体調を定期的に記録・可視化することで、従業員自身が体調の変化を振り返り、セルフケアや必要な配慮・サポートの相談につなげやすくすることを目指します。

### 管理者側の課題

管理者が複数の従業員を担当している場合、それぞれの体調や変化を日々把握することは容易ではありません。

HealthBridgeでは、担当従業員の体調記録を一覧や履歴から確認できるようにし、体調に注意が必要な従業員や未入力の従業員を把握しやすくすることで、必要な声かけや配慮を検討するための情報を提供します。

## 3. 対象ユーザー

HealthBridgeでは、初期運用として従業員10名程度の小規模組織を想定し、以下の2種類のユーザーを対象とします。

### 従業員

- 出勤時・退勤時に自身の体調を記録する
- 自身の過去の体調記録を確認する
- グラフから体調の変化を振り返る

### 管理者

- 担当する従業員の体調を確認する
- 注意が必要な従業員や未入力の従業員を把握する
- 従業員アカウントを管理する
- 必要に応じて担当管理者を変更する

## 5. 主な業務ルール

### 5.1 体調記録

- 体調は「とても良好」「良好」「普通」「注意」「悪化」の5段階とする
- 「普通」を基準として、体調グラフ上で良好側・悪化側の変化を確認できるようにする
- 体調は1日につき「出勤時」「退勤時」の2回記録できる
- 体調記録にはコメントの入力を必須とする
- 同一従業員・同一日・同一記録タイミングの体調記録は1件のみとする
- 従業員は自身の体調のみ記録でき、管理者による代理入力は行わない

### 5.2 未入力の扱い

- 「未入力」は、対象日に出勤時の体調記録が存在しない状態とする
- 退勤時の記録のみが存在しない場合は「未入力」の絞り込み対象には含めない
- 未入力状態を表す体調データは保存せず、体調記録が存在しないことから判定する

### 5.3 従業員と管理者の関係

- 従業員には1人の担当管理者を設定する
- 管理者は自身が担当する従業員の情報・体調記録のみ確認できる
- 従業員アカウントを作成した管理者を、初期の担当管理者として設定する
- 担当管理者を変更した場合も、従業員アカウントと過去の体調記録は保持する

### 5.4 アカウント管理

- メールアドレスはユーザー間で重複しないものとする
- 従業員アカウントを利用停止する場合は、データを削除せず無効化する
- 無効化した従業員についても、過去の体調記録は保持する

## 6. 第2回スタッフレビュー後の確認状況

2026年9月17日の第2回スタッフレビューでは、チーム体調傾向を企業提出版のMVPから外すことを決定しました。それ以外の機能は要望から大きく外れていないとの評価でした。共有メモだけでは以下の個別仕様の承認・確定状況までは確認できないため、実装時にも必要に応じて確認を続けます。

| ID | 確認項目 | 現在の扱い |
| --- | --- | --- |
| F-10 | 担当管理者の変更 | 管理者が従業員の担当を別の登録済み管理者へ変更する現在案を継続して確認する |
| - | 管理者アカウントの登録方法 | 管理者自身が新規登録する現在案を継続して確認する |
| - | 体調5段階の名称 | 「とても良好」「良好」「普通」「注意」「悪化」とする現在案を継続して確認する |
| - | 「未入力」の定義 | 対象日に出勤時の体調記録が存在しない状態とする現在案を継続して確認する |

確認済みのレビュー結果と、今後の確認で得た内容をDBモデル・APIへ反映します。

## 7. MVP対象外・将来拡張

以下の機能は、現時点ではMVPの対象外とし、基本機能の実装・検証後に必要性を検討します。

- 1年間など長期間の体調グラフ表示
- 体調記録が未入力の場合のメール通知
- 無効化した従業員データの一定期間経過後の自動削除
- チーム全体の体調傾向の集計・表示（運用開始後に再検討）
- 大規模組織向けの上位権限、部署・役職情報、従業員検索
