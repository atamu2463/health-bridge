# HealthBridge

従業員が日々の体調を記録し、本人の振り返りと管理者による状況把握を支援する体調管理・共有アプリです。

現在は、就労移行支援事業所のスタッフによる第2回レビューの結果を要件・画面設計へ反映し、Go / PostgreSQLによるバックエンドの基盤構築を進めています。

## デモ

フロントエンドのプロトタイプをVercelで公開しています。

https://health-bridge-management.vercel.app/

> [!NOTE]
> 現在のデモは画面・操作フローを確認するためのプロトタイプです。表示データにはモックデータを使用しており、バックエンドAPI・データベースとはまだ接続していません。

## 開発背景・解決したい課題

### 従業員

日々の体調を記録・可視化することで、自分の体調変化を振り返りやすくし、セルフケアや必要な配慮・サポートの相談につなげることを目指しています。

### 管理者

担当する従業員の体調や変化を把握しやすくすることで、必要な声かけや配慮を検討するための情報として活用できることを目指しています。

## 対象ユーザー

本アプリでは、初期運用として従業員10名程度の小規模組織を想定し、以下の2つのユーザーを対象としています。

- **従業員**
  - 出勤時・退勤時に自身の体調を記録する
  - 過去の体調記録やグラフを振り返る
- **管理者**
  - 担当する従業員の体調を確認する
  - 体調に注意が必要な従業員や未入力の従業員を把握する
  - 従業員アカウントを管理する

## 主な機能

現在、以下の機能をMVPとして設計しています。第2回スタッフレビューでは要望から大きく外れていないことを確認していますが、個別に確認できていない仕様は今後も確認しながら調整します。

### 従業員向け

- 出勤時・退勤時の1日2回、5段階で体調を記録
- 体調とあわせてコメントを記録
- 過去の体調記録を確認
- 1週間・1か月単位で体調の変化をグラフ表示

### 管理者向け

- 従業員アカウントの作成・編集・無効化
- 担当従業員の体調を日付ごとに確認
- 「注意」「悪化」「未入力」による絞り込み
- 従業員ごとの体調履歴・グラフを確認
- 担当管理者の変更

### MVP対象外・将来拡張

- チーム全体の体調傾向は企業提出版のMVPから外し、運用開始後に必要性と仕様を再検討
- 大規模組織向けの上位権限、部署・役職情報、従業員検索

## 開発プロセス

本アプリでは、実装を先に進めるのではなく、利用者の課題を整理したうえで要件・画面を設計し、第三者からのフィードバックを受けながら改善することを重視しています。

1. 解決したい課題・対象ユーザーの整理
2. 機能要件・画面構成の作成
3. フロントエンドプロトタイプの作成
4. 就労移行支援事業所のスタッフによるレビュー
5. フィードバックをもとに要件・画面設計を修正
6. DB・API設計
7. Go / PostgreSQLによるバックエンド実装
8. フロントエンドとバックエンドの接続・改善

## 現在の実装状況

本アプリは現在開発中です。画面プロトタイプとバックエンド・データベースの基盤構築まで進めており、今後、APIの実装とフロントエンドとの接続を進める予定です。

| 項目 | 状況 | 補足 |
| --- | --- | --- |
| フロントエンドプロトタイプ | 実装済み | 主要画面・操作フローをモックデータで確認可能 |
| Docker開発環境 | 構築済み | Frontend / Backend / PostgreSQLをDocker Composeで構成 |
| PostgreSQL | 接続処理実装済み | Go / GORMから接続する処理を実装 |
| HTTPサーバー・Health Check API | 実装済み | `GET /health` で稼働状態を確認可能 |
| DBモデル・マイグレーション | 未実装 | 第2回レビュー結果と今後確認する仕様を反映予定 |
| 業務API | 未実装 | 体調記録などの主要機能から順次実装予定 |
| 認証・認可 | 未実装 | 管理者・従業員の権限制御を実装予定 |
| フロントエンド / API接続 | 未実装 | 業務API実装後に接続予定 |

## 今後の予定

1. 第2回スタッフレビュー結果を要件・DB・API設計へ反映
2. 個別に確認できていない仕様の継続確認
3. GORMによるDBモデル・マイグレーションの実装
4. 体調記録など主要な業務APIの実装
5. 認証・認可の実装
6. フロントエンドとバックエンドの接続
7. テスト・CIの整備
